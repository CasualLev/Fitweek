# Definition of Done

A story is Done only when:

- [ ] Every acceptance criterion is met and checked in the browser
- [ ] Unit and/or integration tests are written for new logic and pass
- [ ] Code is committed with the Jira key in the message and pushed
- [ ] The CI pipeline is green for that push
- [ ] The change is live on the deployed site
- [ ] No errors in the browser console
- [ ] Works at desktop width and at 360px phone width
- [ ] The Jira issue is moved to Done
