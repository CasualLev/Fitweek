# FitWeek'
![CI](https://github.com/CasualLev/fitweek/actions/workflows/ci.yml/badge.svg)

A friendly weekly workout planner that gives beginners a ready-made 4-day exercise plan they can follow, tick off and track through the week.

Built over two simulated sprints for the Agile & DevOps final assessment, using Jira (Scrum) and GitHub.
